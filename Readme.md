# Модульна контрольна робота. Варіант 1 Мосієнко Павло
Номер у списку групи: 21.\
Робота складається з двох завдань.
Залежності:

pip install requests rdflib
## Завдання 1
Використано наданий файл-генератор gen_data.py з сідом 21 який сгенерував файли params.json та flights.csv.\
Після чого створено файл build_graph.py, 
який викликається командою\
- python build_graph.py flights.csv params.json graph.ttl

Скрипт:\
Створює класи та властивості (Flight, Airline, City, Country,
  BudgetFlight, LongFlight),
форматує ID рейсів і назви міст, обробляє дублікати,
форматує дати обох форматів, обробляє затримки як окремі ноди з поля note,
класифікує рейси як BudgetFlight / LongFlight 
за порогами з params.json 
або виставляє Flight якщо рейс не підходить та
серіалізує результат у Turtle (graph.ttl).

## Завдання 2
Для мого номера у списку групи 21/6 = залишок 3:\
стадіони (Q483110), Італія (Q38), місткість (P1083), поріг 20000.
- q1.rq, q2.rq, q3.rq це SPARQL-запити до Wikidata
- run_queries.py виконує запити, зберігає відповіді запитів у q1.csv, q2.csv, q3.csv і записує час виконання у meta.json
- meta.json файл з часом виконання
- ANSWERS.md зберігає дані за першими рядками відповідей на запити

Для виконання використайте команду 
- python run_queries.py
